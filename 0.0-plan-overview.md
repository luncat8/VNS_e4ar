# VNS_e4ar — Visual Novella Scroll Engine — Plan Overview

## Concept
Text scrolls, backgrounds ride with it like wagons. Current wagon parks
at viewport top (`top:0`) until next wagon collides with its bottom and
pushes it off. Styles morph smoothly between anchors. Declarative
`type="txt"` scripts fire on scroll states. All free-placed in DOM, no
strict section tree, `file://` friendly, no build, classic `<script>`.

## Plan Sequence — implement in order
1. **0.1 — Test Harness** — generator for text/chapters and visuals.
   Must land first: gives manual QA surface and exposes wagon bugs
   without needing engine code. No engine dependency.

2. **0.2 — Wagon Engine** — core. Depends on 0.1 DOM. Implements
   park/push math, size modes (`cover|contain|fixed|original`),
   `data-dir` pushes, reversible rAF loop. Hardest, most bug-prone.

3. **0.3 — Style Morph** — independent controller that piggybacks on
   same rAF. Depends on 0.1 anchors, optional 0.2. Lerps CSS vars and
   toggles classes between `data-bg`/`data-style` anchors.

4. **0.4 — Script Events** — edge-triggered `view|center|parked|end|skip`
   execution of inert `<script type="txt">`. Depends on 0.1 anchors and
   0.2 parked state; works standalone with degraded `parked`.

Each plan is self-contained spec: DOM contract, algorithm, test matrix,
acceptance criteria. Implement one, pass its criteria, then next.
Archive completed plan to `archive/` per AGENTS.

## File/Layout Contract
- `index.html` — harness + engine `<script>` tags, `file://` safe.
- `.bg` / `.bgwindow` — fixed + `translate3d`, placeholder anchors.
- `[data-bg],[data-fg],[data-style]` — style anchors.
- `script[type="txt"][event]` — event scripts.

## Global Invariants (all plans)
- Document order = logical order (wagons, styles, scripts all sorted by Y).
- No overlap of wagons (except lateral `data-dir` exit).
- Fully reversible: same `scrollY` → same layout/style, regardless of
  scroll direction/history.
- No allocations/closures in rAF hot path; preallocate, mutate in place.
- Single tab indent, early returns, flat helpers, `const $ = id => document.getElementById(id)`.
- `will-change:transform`, `translate3d` for wagons.

## How To Verify Progress
Open `index.html` via `file://`, use harness controls (chapters, gap,
bg mode), scroll slow/fast/both directions, watch diagnostics overlay
and console. Each plan's Acceptance Criteria is the gate.

## Out Of Scope For These Plans
- Build step, modules, npm, network images.
- Parallax speed factors.
- Timeline GUI editor.
