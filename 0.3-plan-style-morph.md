# 0.3 — Style / Theme Morph Engine

## Goal
Smooth visual transition of page theme (background colour, text style,
menu, vignettes) while scrolling between chapters, like sunset or
opening a door to a bright room — interactive, not a blink. Driven by
declarative attributes on wagons/sections, no imperative JS per chapter
by author.

## Non-goals
- Not a full CSS-in-JS framework.
- Not per-pixel shader; keep to CSS custom properties and class toggles
  that compose with 0.2 wagons.
- No timeline editor — author just marks anchors.

## DOM Contract
Author may set style at any element (section, `.bg`, loose `<div>`):
```html
<section data-bg="#0b1020" data-fg="#e8e6e1" data-style="night">
<div class="bg" data-bg="#ffe8a0" data-style="sunset"></div>
<p data-style="bright">text</p>
```
- `data-bg` — page/overlay background colour (hex/rgb/gradient token).
- `data-fg` — foreground/text colour.
- `data-style` — one or more class names to apply to `<html>` or
  `#app` (e.g. `night`, `day`, `fog`). Classes defined in author CSS.
- Optional `data-range="200"` — morph duration in px of scroll after
  anchor before style fully settles (default `Hv*0.6`).
- Free placement inherits same rule as wagons: style anchors are
  ordered by document `Y`, independent of section nesting.

## Architecture
Single `StyleMorph` controller, shares anchor measurement with 0.2
(placeholders or shared `Y[]`). No extra scroll listener — piggybacks
on 0.2 rAF dirty flag or own rAF if 0.2 absent.

State: arrays `Y_s[], bg[], fg[], cls[][], range[]` sorted by Y.
Pre-allocated `cssVars` object reused per frame.

Per frame:
```
idx = lowerBound(Y_s, scrollY + Hv*0.5) // active chapter near centre
prev = idx-1, next = idx
t = clamp((scrollY - Y_s[prev]) / range[prev], 0, 1)  // 0..1 between anchors
// colours
bg = lerpColor(bg[prev], bg[next], ease(t))
fg = lerpColor(fg[prev], fg[next], ease(t))
// apply without layout thrash
root.style.setProperty('--vns-bg', bg)
root.style.setProperty('--vns-fg', fg)
// classes: cross-fade by toggling with opacity transition
if(cls[next] !== activeCls) { swap classes, trigger CSS transition }
```
- `lerpColor` — hex→rgb lerp in linear sRGB, reused scratch arrays,
  no allocations. Gradient tokens (e.g. `gradient:sunset`) lerp via
  predefined stops table (flat array).
- `ease(t)` — `t<0.5 ? 2*t*t : 1-pow(-2*t+2,2)/2` (easeInOutQuad),
  cheap, avoids harsh blink.
- CSS consumes vars:
```css
html{ background: var(--vns-bg); color: var(--vns-fg); transition: background 0.4s, color 0.4s }
#app{ transition: filter 0.4s }
.night{ filter: brightness(0.85) contrast(1.05) }
```
Author can define `.night`, `.sunset` etc; engine only toggles class
names and vars — author CSS decides actual look.

## Interaction With Wagons
- Style anchor and wagon anchor may be same element (`.bg` with both
  `background-image` and `data-bg`) or separate. Engine treats them as
  two independent ordered lists but both sorted by Y; no coupling.
- When a wagon parks at `top:0`, style lerp continues smoothly — wagon
  image and page tint can co-exist (e.g. cold to warm while wagon
  holds). No z-index fight: wagons fixed behind text (`z-index: -1`),
  style vars affect text/app layer above.

## Performance & Style
- Single tab indent, flat functions `lerpColor(out, a,b,t)`, `ease(t)`.
- No object literals in frame; colour scratch `r0,g0,b0,r1,g1,b1` in
  closure.
- Batch DOM writes after reads; one `style.setProperty` per var.
- `file://` friendly: no CSS `@import` from network.

## Test Matrix (extends 0.1 harness)
- Harness adds per-chapter `data-bg` cycling red→blue→yellow and
  `data-style` toggling `night`/`day`. Scroll slowly — colour should
  glide, not snap.
- `data-range` short (80 px) vs long (800 px) — short snaps quick,
  long glides over entire chapter.
- Free-placed `data-bg` between text lines (not section-bound) — still
  lerps at its Y.
- `cover` wagon + `data-bg` on same element — both apply.
- Reverse scroll — colours exactly retrace (lerp is pure function of
  scrollY).

## Acceptance Criteria
- [ ] Scrolling from chapter A to B interpolates `--vns-bg`/`--vns-fg`
  smoothly over `range` px without step/jump.
- [ ] Class in `data-style` becomes active when its anchor passes
  viewport centre (±50 px) and previous class removed (one active at a
  time if author marks exclusive, additive if multiple).
- [ ] No layout shift from style change (only paint/filter).
- [ ] Works with 0.2 wagons enabled and with wagons disabled (standalone).
- [ ] Adding new `data-bg` element between chapters via harness Regen
  updates morph without reload (calls `refresh()`).

## Pitfalls
- Do not animate `background-image` itself — only vars/classes.
- Do not use `scroll` event to set style directly; use rAF to avoid
  jank and to keep colour lerp in sync with wagon transforms.
- Guard against missing `data-bg` between anchors: hold previous value
  (no lerp to undefined).
- Author free placement means style anchors must be collected via
  `querySelectorAll('[data-bg],[data-fg],[data-style]')` in document
  order, not via section traversal.

## Future Hook
0.4 script events can observe style progress (e.g. `event=style:50%`)
if needed, but not required for this plan.
